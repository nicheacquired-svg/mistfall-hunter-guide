Mistfall Hunter Patch Notes & Roadmap

📅 Updated: August 2026 📖 Mistfall Hunter Guide

Stay up to date with the latest Mistfall Hunter patches, balance changes, and the development roadmap. This page covers the most recent updates and what's coming next.

Latest Update: August 6, 2026

The August 6 patch (09:00 UTC) brought significant content and fixes:

New Content

  • Dried Flower Knot - New item now dropping in-game
  • Einherjar Mist Lord Challenge - New endgame PvE challenge added

Balance Changes

  • Blackarrow - Adjusted escape skill energy cost (increased)
  • Withered Knight - Buffed (specific tuning details in official patch notes)
  • Sorcerer - Received buffs in this cycle

Bug Fixes

  • Fixed multiple crash issues
  • Fixed multiplayer disconnection bugs
  • Fixed Hallowgrove Gyldenmist behavior inconsistencies
  • Fixed Soul Tree getting players stuck
  • Fixed Fate Chart display issues
  • Various UI and interface fixes

Previous Patch: July 30, 2026

The day-one patch focused on controller and platform-specific bugs:

  • Fixed leaderboard cursor crash on controllers
  • Fixed Loadout inability to unequip items with controller
  • Fixed auction house gem slot interaction
  • Fixed training room settings not saving
  • Fixed PS5 interface anomaly
  • Fixed Xbox PC exit error popup

Known Issues (As of August 7)

The developers are actively investigating:

  • Stuttering and lag - Performance issues affecting all platforms
  • Latency spikes - Particularly in certain server regions
  • Platform-specific issues due to certification delays causing asynchronous updates

Development Roadmap

The official roadmap spans three phases for Season 1 and beyond:

Phase 1 (Current - August)

  • Einherjar difficulty mode
  • Mistlord Challenge (new endgame content)
  • Soul Harvest event
  • Soulgnawer - New boss

Phase 2 (September)

  • Brandrgarde solo mode - Normal and Cataclysm difficulties
  • Season Tasks system unlock
  • Underlord Speed Challenge

Phase 3 (Later in Season 1)

  • Golden Woodling - New enemy type
  • Ancestor Tree event

Season 2 Teaser

Blackarrow will receive a new weapon: the Javelin (throwing spear), expanding the class's arsenal beyond the bow.

Update Cadence

Mistfall Hunter follows a weekly balance patch schedule with hotfixes as needed. Due to platform certification processes, updates may not hit all platforms simultaneously. The Steam news page and changelog.gg are the most reliable sources for full patch note text.

Stay Updated

For the latest patch notes, check: Steam News page, official Discord (#announcements), changelog.gg/games/mistfall-hunter-3282300/updates, or the official website's DevNote section.
