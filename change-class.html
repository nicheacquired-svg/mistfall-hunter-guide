How to Change Class in Mistfall Hunter

📅 Updated: August 2026 📖 Mistfall Hunter Guide

Regretting your starting class? Good news: Mistfall Hunter does not lock you into the class you picked at character creation. You can switch classes on the same character, or unlock extra character slots entirely. Here is exactly how it works.

Can You Change Class?

Yes. After completing the prologue and your first expedition, class switching unlocks at your camp hub. Your first switch is free, so experimenting early costs you nothing.

How to Switch: Talk to Dew

Dew is the NPC at camp who guides you through the game's early quests - and she handles class management:

  1. Complete the prologue tutorial and finish your first Hallowgrove run (win or lose)
  2. Return to camp and find Dew
  3. Select the Switch Class option in her dialogue
  4. Pick any of the six classes from the list and confirm
  5. Your character swaps immediately - test the new kit in the training arena or jump into a run

Class options: Mercenary, Sorcerer, Blackarrow, Shadowstrix, Seer, and Withered Knight.

Costs, Cooldowns & Reverting

DetailRules

What Carries Over Between Classes

Each class levels independently. Switching does not merge progress:

FeatureShared?
Character (same slot)Yes
Gold / GyldenblodYes
Warehouse / stashYes
TalentsNo - per class
SkillsNo - per class
Class progressionNo - starts fresh per class
Equipment loadoutsSeparate per class

Weapons and armor are class-specific, so keep valuable gear in your warehouse before switching - some items become unusable with the new class.

Character Slots: The Alternative

Instead of switching one character back and forth, you can run multiple characters, one per class:

  • You start with 3 character slots
  • At level 6, Dew unlocks the camp upgrade system
  • Upgrading the Gyldenblod Pool (the basin in front of Dew) to levels 3 through 9 grants one extra slot each
  • Maximum: 10 character slots
  • All slots share the account warehouse; each levels separately from level 1

To create a new character: press Esc → Select Character → click the + icon.
