Mistfall Hunter Development Roadmap

📅 Updated: August 2026 📖 Mistfall Hunter Guide

Three-phase post-launch roadmap covering Season 1 through Season 2.

Roadmap Overview

PhaseTimingContent
Phase 1Launch (July 2026)Einherjar difficulty, Mistlord Challenge, Soul Harvest, Soulgnawer boss
Phase 2September 2026Brandrgarde solo mode, Season Tasks, Underlord Speed Challenge
Phase 3TBAGolden Woodling, Ancestor Tree event

Phase 1 (Current)

  • Einherjar Difficulty — Highest tier; requires Dried Flower Knot; drops Holy weapons
  • Mistlord Challenge — Otto the Flesheater + Harald the Fallen General
  • Soul Harvest Event — Limited-time event
  • Soulgnawer — New boss (August 6 update)

Phase 2 (September)

  • Brandrgarde Solo Mode — Normal and Cataclysm; most requested feature
  • Season Tasks — Task/achievement system
  • Underlord Speed Challenge — Timed boss challenge

Phase 3 Preview

  • Golden Woodling — New enemy type
  • Ancestor Tree Event — Community event

Season 2 Preview

  • Blackarrow new weapon: Javelin — Thrown spear stance

Long-term Direction

  • Camp social features and mini-games (in development)
  • DualSense haptic feedback (future update)
  • Weekly balance patches
  • OCE servers under consideration
Stay Updated

Summary

Phase 1 (Einherjar + Mistlord), Phase 2 (Brandrgarde solo in September), Phase 3 (Golden Woodling + Ancestor Tree). Season 2 teases Blackarrow Javelin. Long-term: camp social features, DualSense support.
