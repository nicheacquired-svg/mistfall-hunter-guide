What Critics Praise

  • The combat - a positioning-and-parry-focused soulslike core that PC Gamer compared to God of War (2018)
  • The extraction loop - PvPvE tension where a successful escape with loot feels genuinely earned
  • Class variety - six classes with dual weapon stances create meaningful build diversity
  • Long-term potential - several reviewers see the seasonal framework as a strong foundation

What Critics Criticize

  • Launch performance - stuttering, shader compilation, and server instability
  • Class balance - some archetypes handle multiple roles more frustratingly than contemporaries
  • Content variety - repetition fatigue sets in for some reviewers within hours
  • Region locking - server restrictions prevent free region switching (no Oceania servers)
  • Unmoderated global chat - a moderation problem flagged pre-launch that has dragged on reception

Critic Score vs User Score

There is a gap worth understanding. Critics average around 7/10, while Steam sits at ~58% positive. Two factors explain much of it:

  1. Language split: English-language Steam reviews trend noticeably more positive than the large Simplified Chinese review pool, which skews negative (partly tied to server and regional issues)
  2. Day-one patch churn: early user reviews captured the roughest launch state; the rating has been recovering since

For the live player-count picture behind these numbers, see Player Count and SteamDB stats.

Bottom Line

A 69 Metascore means "mixed but worthwhile if the genre fits you." The consensus: strong combat and a solid extraction skeleton, wrapped in a typically rough live-service launch. At $24.99 - or free with Game Pass - it is a low-risk try. Start with our Beginner Guide if you are diving in.
